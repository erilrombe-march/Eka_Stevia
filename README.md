# ❤️ ANIMASI LOVE

Program animasi hati menggunakan Python dengan tulisan I LOVE YOU.

## ✨ Fitur
- Animasi tulisan I LOVE YOU berbentuk hati.
- Animasi hati berputar.
- Lirik lagu ditampilkan di sebelah kiri.
- Musik latar menggunakan Pygame.
- Dibuat menggunakan Python Turtle.

## 🛠️ Teknologi
- Python 3
- Turtle
- Pygame

## 📦 Instalasi

Install Pygame terlebih dahulu:

```bash
python -m pip install pygame
```

## ▶️ Cara Menjalankan

1. Simpan file Python dan `1010.MP3` dalam satu folder.
2. Buka terminal di folder proyek.
3. Jalankan perintah:

```bash
python tes.py
```
